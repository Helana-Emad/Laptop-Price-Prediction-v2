About The Project

This platform is designed to provide accurate market price estimations for laptops using machine learning regression techniques. It assists users in determining fair values for both new and refurbished devices based on their exact hardware specifications.

Tech Stack

Machine Learning: Python, CatBoostRegressor, Scikit-Learn

Backend API: FastAPI, Uvicorn, Pydantic

Frontend: HTML5, CSS3, JavaScript
